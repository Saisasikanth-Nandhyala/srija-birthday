# Srija Birthday Surprise

Open `index.html` in a browser to preview the surprise.

To publish it:
1. Create a GitHub repository.
2. Upload `index.html` and the `photos` folder.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> /root.
4. GitHub will give you a shareable `github.io` website URL.

The melody is generated in the browser, so no copyrighted music file is included.
